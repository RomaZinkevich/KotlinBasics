# KotlinBasics in Brainfuck

Every exercise is now a `.bf` file where its `.kt` used to be. The data sits on the tape and the programs do the work themselves: `a + b`, `a % 2`, `uppercase()`, the `olderthan30` filter, `addItem` and `changeDesc` on the weather list, and the data class `toString`, `copy` and `==`.

Run any of them with an 8-bit Brainfuck interpreter:

```sh
bf Week4/Lists.bf
```

Doubles are stored in tenths, so `11.5` is the cell value `115`.
